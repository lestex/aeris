# Backgrounds

Drop images here to ship them with AerisOS, or in `~/Pictures/backgrounds/`
for ones that are only yours. Per-theme wallpapers go in
`themes/<name>/backgrounds/`, which `aeris-background` prefers when that theme
is active — the same arrangement Omarchy uses.

Omarchy's own wallpapers were deliberately **not** copied: they are images
with their own provenance, and the repository's MIT license covers its code,
not every asset inside it.

`jpg`, `jpeg`, `png` and `webp` are picked up. With no images present the
desktop shows the active theme's background color, which is a working state
rather than a missing one.
